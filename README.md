# 婚礼邀请函 · wedding invite

邹铭杰 ❤ 丁沄芷 · 2026-10-17(周六)

单文件婚礼请柬页面,7 页翻书式设计,手机优先,零依赖(无框架、无构建),直接打开即可预览。

## 运行

任意静态服务器即可,例如:

```bash
cd invite && python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

直接双击 `index.html` 也能看,但个别浏览器对 file:// 下的交互有限制,建议用上面的方式。

## 目录结构

```
invite/
├── index.html            # 完整页面(样式/脚本内联,所有内容都在这里)
├── photos/               # 9 张照片,页面实际引用
├── assets/art/           # 10 张水彩素材,目前未在页面中使用,改版备用
└── reference/
    └── guest-fields.json # 飞书回执表单(多维表格)的字段定义,改表单时参考
```

## 页面结构(7 页,index.html 内以 data-idx 区分)

| 页码 | 内容 | 主要信息位置 |
|---|---|---|
| P1 | 封面 | 新人姓名、日期 2026/10/17 |
| P2 | 邀请文 | 婚礼日期(二〇二六年十月十七日·周六) |
| P3 | 时光画廊 | 5 张拍立得拼贴 |
| P4 | 婚礼安排 | 时间轴(17:08 迎宾 / 18:18 仪式 / 18:38 晚宴) |
| P5 | 婚礼地点 | 杭州国际博览中心 4B 紫云阁 + 导航按钮 + 交通方式 |
| P6 | 大图寄语 | 文案「执子之手 · 与子偕老」 |
| P7 | 出席回执 | 跳转飞书表单填表 |

翻页支持:点击左右两侧、底部圆点、左右箭头、键盘方向键、触摸滑动、桌面滚轮。URL 加 `?p=3` 可直接跳到指定页。
